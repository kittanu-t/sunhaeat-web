# Design direction: จานสังกะสี

**ฉากใช้งาน:** คนหิวถือมือถือกลางวัน ยืนเลือกร้านกับเพื่อน จึงเป็นธีมสว่าง อ่านเร็ว นิ้วโป้งกดถึง โหมดหลักคือ Operate (หา → ตัดสินใจ) ไม่ใช่หน้าโฆษณา

**โลกภาพ:** จานเคลือบสังกะสีในร้านอีสาน ผิวขาวอมฟ้า ขอบน้ำเงินโคบอลต์ และสีจากอาหารบนจาน (พริก มะนาว ขมิ้น) ชื่อเว็บใช้ตัวเขียนแบบป้ายร้านเพียงจุดเดียวต่อหน้า

| Token | ค่า | ใช้กับ |
|---|---|---|
| `--enamel` | `#f6f9fc` | พื้นหน้า |
| `--plate` | `#ffffff` | การ์ด แผง |
| `--rim` | `#1d3f9a` | ขอบจาน ลิงก์ ปุ่มหลัก หมุด |
| `--rim-soft` | `#c9d5ee` | เส้นแบ่ง ขอบรอง |
| `--ink` / `--ink-2` | `#14213d` / `#44526f` | ข้อความหลัก / รอง |
| `--chili` | `#c22f1f` | สิ่งที่เลือกอยู่ ข้อผิดพลาด |
| `--lime` | `#2f6b2a` | ตรงเงื่อนไข |
| `--turmeric` | `#f4c542` บน `--ink` | ป้ายร้านตัวอย่าง (สมมติ) |

- **Type:** IBM Plex Sans Thai Looped (เนื้อความ มีหัว อ่านง่าย) 16/26px; Pattaya เฉพาะ wordmark และชื่อร้านบนเพจ; ตัวเลขใช้ tabular
- **รูปร่าง:** รัศมี 14px, ขอบจาน 2 ชั้น (เส้นน้ำเงิน + ช่องว่างขาว) เป็นลายเซ็น ใช้กับจานปกและปุ่มหลักเท่านั้น
- **ปกเพจ:** ไม่มีรูปร้านจริง จึงวาด SVG จานพร้อมอาหารตามแท็ก ห้ามใช้ภาพที่ชวนเข้าใจว่าเป็นร้านนั้น
- **Layout มือถือ:** ค้นหา → แผนที่ 38vh → รายการ; ปุ่มลอย “คุยกับ AI” **Desktop ≥960px:** รายการ 440px ซ้าย แผนที่เต็มขวา
- **Motion:** หมุดที่เลือกขยาย 160ms ease-out จุดเดียว; เคารพ `prefers-reduced-motion`
- **ความซื่อตรงของข้อมูล:** “ยังไม่มีข้อมูล” แสดงเท่ากับข้อมูลจริง ไม่ซ่อน; ป้ายร้านตัวอย่างเห็นก่อนชื่อ
- **ไม่ทำ:** gradient text, glass, kicker, emoji เป็นไอคอน, การ์ดซ้อนการ์ด
