## สิ่งที่พบและผลต่อแผน
1. `operating_status` เป็น null 97,559 จาก 97,560 แถว ใช้กรองร้านปิดไม่ได้ ต้องไม่อ้างว่าร้านเปิดอยู่
2. `update_time` ของ sample ส่วนใหญ่เป็นวันเดียวกัน (2026-11-02) จึงดูเหมือนวันนำเข้า ไม่ใช่วันที่ยืนยันร้าน ห้ามแสดงเป็น “อัปเดตล่าสุด”
3. แหล่งหลักคือ Meta 96.5% (29,345/30,398, CDLA-Permissive-2.0); AllThePlaces (CC0) 1,046; Microsoft 7
4. เบอร์จำนวนมากเป็นมือถือ อาจเป็นข้อมูลส่วนบุคคลของเจ้าของร้าน จึงเสนอไม่นำเข้าใน R1; มี 23 ชื่อที่ฝังเบอร์ ต้องตัด
5. หมวดหยาบ/ผิด: 33.3% เป็น `restaurant` เฉย ๆ; `ramen_restaurant` 758 ร้าน มี 516 ร้านที่ชื่อมี “ก๋วยเตี๋ยว”; โจ๊กและปาท่องโก๋ถูกจัดเป็น `coffee_shop` ต้องติดแท็กจากชื่อไทยเอง
6. ตัดซ้ำแบบ grid ยังเหลือร้านเครือที่สะกดต่างกันข้ามแหล่ง เช่น อเมซอน
7. Gemini limits ยังไม่ได้ตรวจ เพราะต้องใช้บัญชีผู้ใช้
